## 🔨 Featured projects

### BudOblik — accounting system to replace 1C
A web system for a construction-materials company: products and price types, warehouse stock (average / FIFO cost), documents, payments and debts, accounting with VAT, CRM, and migration from 1C via Excel. Access roles, two-factor login and a tamper-proof audit log.

- **Stack:** React, Vite, Tailwind, Fastify, PostgreSQL, Drizzle ORM, Docker
- **Tests:** 280+ automated tests — access rights, document posting, cost price, VAT, 1C migration
- **My part:** requirements, architecture, roles and security, UI design, reviewing every change. An AI agent writes code and tests from my spec.
- 🔗 **[Live demo](https://budoblik-demo.onrender.com/login)** — click any role card, password `demo1234` (demo data only). The source code is private: the system is built for a real company.

### ONE BUG — co-op 3D game
Rubber ducks with jetpacks search for one real bug in a neon city built out of code. Now growing into a co-op roguelike.

- Online co-op for up to 4 players, 3 classes with talent trees, bosses, item physics, UA/EN
- **Stack:** Rust, Bevy, Avian physics, automated tests for game logic
- **Status:** prototype, two playtests done
